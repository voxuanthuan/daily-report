# Jira Daily Report

Terminal tool (Go TUI + CLI) for managing Jira tasks, logging time to Tempo, and generating the daily report.

## Language

**Daily report**:
The summary produced by `jira-report generate`: work logged on the previous workday (from Tempo worklogs), today's in-progress Jira tasks, blockers, and a todo list.
_Avoid_: standup, standup report, daily standup report
